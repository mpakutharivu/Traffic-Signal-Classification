
# Traffic Sign Classification using Image Processing & Machine Learning

This project implements a **traffic sign classification system** using **image processing and machine learning techniques** in Python. The goal is to automatically recognize and classify road traffic signs from images, a key component in **autonomous driving** and **intelligent transportation systems**.

---

## Project Overview

Traffic sign recognition is essential for improving road safety and enabling driver-assistance systems. In this project, traffic sign images are preprocessed, analyzed, and classified into their respective categories using machine-learning-based feature learning.

The notebook demonstrates the complete workflow:

* Image preprocessing (resizing, normalization, noise handling)
* Feature extraction and representation
* Model training and classification
* Performance evaluation and visualization of results
